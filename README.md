# Web MacOS Clone

A web-based clone of macOS built with React and Vite.

## Features

- **Desktop Environment**: Customizable wallpaper, context menu.
- **Window Management**: Draggable, resizable windows with minimize/maximize/close controls.
- **System UI**: Menu bar, Dock with bouncing animation.
- **Applications**:
  - Finder
  - Calculator
  - Notepad
  - Solitaire
  - Chinese Chess
- **Login Screen**: Simulated login experience.

## Getting Started

1.  Clone the repository.
2.  Run `npm install`.
3.  Run `npm run dev` to start the development server.
